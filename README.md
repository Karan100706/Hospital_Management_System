   ## Hospital Management System (HMS)

### Project Overview
The Hospital Management System is developed using Python and Streamlit. It helps manage hospital activities through a simple user interface.

### Technologies Used
- Python
- Streamlit
- SQLite
- Pandas

### Project Files
- `app.py` – Main HMS application
- `requirements.txt` – Required Python libraries
- `patient_registration_notes.md` – Patient registration module documentation

### Software Configuration Management
GitHub is used to maintain the project source code and its versions.

The following activities were performed:
1. Created a GitHub repository.
2. Uploaded the HMS application files.
3. Created a feature branch for development.
4. Committed changes to the branch.
5. Created a pull request to merge changes into the main branch.
6. Merged the pull request.
7. Published release `v1.0.0`.

### How to Run
